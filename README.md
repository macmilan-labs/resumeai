# ResumeAI

Modern AI-powered ATS resume optimization platform built using React, Node.js, Express, and TailwindCSS.

ResumeAI helps job seekers improve their resumes by analyzing them against job descriptions and generating actionable ATS-focused optimization insights.

---

# Features

## ATS Resume Analysis

* ATS compatibility scoring
* Resume vs Job Description comparison
* Keyword matching system
* Missing skills detection
* Recruiter-focused optimization suggestions

## Smart Results Dashboard

* Dynamic ATS score visualization
* Skill alignment analysis
* Critical gap detection
* Resume verdict generation
* Priority improvement recommendations
* AI-style rewrite suggestions
* Recruiter readability insights

## User System

* Authentication flow
* Free and Pro user experience
* User-specific history tracking
* Persistent analysis records
* Clear history functionality

## Modern SaaS UI

* Multi-page architecture
* Responsive premium dashboard
* Animated UI components
* Modern blue & orange design system
* Interactive analysis workspace
* React Router navigation

# Installation & Setup

## Clone Repository

```bash
git clone https://github.com/macmilan-labs/resumeai.git
cd resumeai
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```
